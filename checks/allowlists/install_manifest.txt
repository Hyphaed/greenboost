# Installer/uninstaller parity manifest — checks/check_installer_parity.py.
# One line per Full-Install artifact: "name | install_regex | purge_regex".
# Both regexes are searched (re.search, DOTALL off) against the whole
# greenboost_setup.sh text — not anchored to a specific line range, since
# line numbers drift as the script grows. Add a new line in the SAME change
# that adds a new installed artifact (systemd unit, MCP registration,
# wrapper, venv, config file) — this is the mechanized half of
# golden-principles.md #3.
#
# Verified 2026-07-13 (first-run audit): every entry below was checked
# against the live script, not assumed from memory.
